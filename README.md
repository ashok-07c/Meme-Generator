# 🎭 Meme Generator

A fun and interactive Meme Generator built with React and Vite that allows users to create customized memes using random templates fetched from the Imgflip API.

## 🚀 Features

- Generate random meme templates
- Add custom top text
- Add custom bottom text
- Real-time meme preview
- Responsive UI
- API integration with Imgflip

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- Imgflip API

## 📂 Project Structure

src/
├── Components/
│ ├── Header.jsx
│ └── Main.jsx
├── Images/
│ └── image.png
├── App.jsx
├── main.jsx
└── index.css

## ⚙️ How It Works

1. Meme templates are fetched from the Imgflip API when the application loads.
2. Users enter top and bottom text through input fields.
3. Clicking "Get a Meme Image" randomly selects a meme template.
4. The custom text is displayed on the selected meme image.

## 🔥 Key Concepts Practiced

- React Components
- useState Hook
- useEffect Hook
- Controlled Inputs
- Event Handling
- API Fetch Requests
- Dynamic Rendering
- State Management

## ▶️ Installation

1. Clone the repository

git clone <repository-url>

2. Navigate to the project folder

cd meme-generator

3. Install dependencies

npm install

4. Run the development server

npm run dev
